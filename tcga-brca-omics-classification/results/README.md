# Results

This directory is for compact, reproducible outputs generated by the analysis.

Recommended files to commit after running the project:

- `nested_cv_summary.csv`
- `heldout_metrics.csv`
- `bootstrap_ci.csv`
- `top_stable_features.csv`
- `gprofiler_basal_high.csv`
- `gprofiler_luma_high.csv`

Large intermediate outputs such as per-bootstrap samples and the complete
gene-level differential-expression table are ignored by Git.
